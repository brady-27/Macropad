# Macropad
A small macropad to get comfortable with 3d design, cad, printing, and pcb design
The main goal of this macropad is to make a device that I can easily access physically to control media like spotify. I plan to make a pad with 3 keyboard switched, a rotary encoder, and and small led screen. 
The 3 keys are going to be [Previous] / [Pause/Resume] / [Skip]
